# 演示视频录制清单（I5 · 可重做版）

录制标准（《计划 v3.0》§7）：实测 **5:00–8:00**、AI 协同段 **≥2:00**、**1080p 可过审**。
本文件只写"在哪个 commit 上、敲哪几条命令、点哪里、屏幕上应该出现什么"，
不写旁白定稿——旁白见 §11 的三反例讲法。

## 0. 录制前的一次性准备

```bash
cd D:/project1/intentform
git log --oneline -1                 # 记下这个 hash，填进第 7 节的表
pnpm install                         # 只在依赖变动后需要
pnpm build:web                       # 发布页/看板走 dist 时需要
```

**开录前必须做一次**，否则画面里会出现"过期的旧行为"：

```bash
node scripts/verify.mjs              # 期望 VC1..VC4 4/4
node scripts/browser-closed-loop.mjs # 期望 6 步全绿，截图刷新到 docs/evidence/
```

跑完把 `docs/evidence/README.md` 的「最近一次运行」核对一遍，与本机 `git log -1` 不一致就重跑。

两套环境（分段切换，别边录边改环境变量）：

| 用途 | 命令 | 说明 |
|---|---|---|
| A：回放（无 Key 也能录，第 1、2、6 段） | `LLM_MODE=replay PORT=8787 node --experimental-strip-types server/src/main.ts` + `VITE_DEV_PROXY_TARGET=http://127.0.0.1:8787 pnpm --filter @intentform/web dev` | 打 `fixtures/replays/` 的三条录制，事件序列与真上游同形 |
| B：mock（第 3 段门禁、第 4–5 段闭环） | 同上，把 `LLM_MODE=replay` 换成 `LLM_MODE=mock` | 内置脚本，含一条故意写坏再修复的题；**不出网** |

> 真 Key（`LLM_MODE=live`）只在你想展示"真的在调模型"时用。没有 Key 就**不要**在视频里
> 声称是 live——回放模式的时间线与事件是真代码跑的，模型输出是录下来的，这段差别要说出来。

## 1. 分镜与实机路径

| 段 | 时长 | 环境 | 怎么点到 | 屏幕上必须看见的 |
|---|---|---|---|---|
| 1 需求 → 逐字段生成 | 1:30 | A | `/` 三栏页，点预置按钮「初二数学·二次函数」→ 点「开始生成」 | 左栏需求、中栏字段**一张张出现**（不是一次性刷出）、右栏时间线同时推进；顶栏数据源标记为 **回放**，不是 `live` |
| 2 时间线：阶段与耗时 + 一行修复 | 1:00 | A | 停在生成完成那屏，滚右栏时间线 | `理解 → 规划 → 生成 → 校验 → 修复 → 完成` 六阶段与各段耗时；修复轮条目能点开看"改了什么"（不显示推理原文——那是 §2.4 明确删掉的） |
| 3 整表门禁拦一次不合格生成 | 0:40 | B | 输入一段"要求出 5 道但没给分值"的需求 → 生成 → 点「保存并发布」 | 发布被拒，面板红字给出 `错误码@路径`（如 `E_SCORE_SUM@items[2]`），**没有**学生链接；顶栏生成次数/耗时如实 |
| 4 发布 → 手机 → 判分 → 看板/CSV | 1:40 | B | 生成成功后点「保存并发布」→ 复制学生短链 → 开 390×844 视口 → 逐题作答 → 提交 → 回看板 → 点「导出 CSV」 | 短链形如 `/f/xxxxxxxx`；手机页无横向滚动、单选圆点**实心**；提交卡片给分；看板出现这一行；CSV 表头里**没有** answer 列 |
| 5 收集页 → 回收 → CSV | 0:50 | B | 看板选「问卷」那张表 → 学生页填完 → 回看板导出 | 问卷不判分（显示"已记录"而非分数）、平均分栏为空/0 的口径与注释一致 |
| 6 回放模式现场复现（无 Key） | 0:50 | A | 终端敲 `node scripts/verify.mjs`，再敲一次第 1 段同一个预置 | 4/4 通过；同一条需求播出的字段序列与第 1 段**一字不差**——这是"可复现"的直接证据 |
| 7 AI 协同段（真实会话） | ≥2:00 | — | 屏幕录制 DSH 会话：提出问题 → 我的改法 → 某条被否决的建议 → 真实 bug 被定位到修复 | 至少一次真实的"错了 → 查 → 改"闭环；不许用"我早就知道"式剪辑 |

总时长按 1:30+1:00+0:40+1:40+0:50+0:50 = **6:30**，加 AI 段 2:00 ≈ **8:30**，压到 8:00 以内时
优先砍第 5 段（收集页回收在 CSV 段已有画面）。

## 2. 录制参数

- 分辨率 1920×1080，浏览器缩放 100%，hide bookmarks bar；手机段用 **390×844** 设备模拟并保持同一窗口。
- 终端字号 ≥16pt，深色底；命令一条一条敲，不要粘贴出一整屏。
- 每段单独录，剪辑时按上表拼；**不要**在同一段里改环境变量或切 commit。
- 画面里不要出现：`.env`、任何 Key、`data/*.db`、其它项目的窗口。

## 3. 每段开头的"版本字幕"

第一帧叠一行小字（不可后期造假，必须是录制当时 `git log -1` 的值）：

```
意卷 IntentForm · <commit hash> · LLM_MODE=<replay|mock|live>
```

这一段的作用是让评审能把视频和仓库对上；没有它，视频只能算"某人某时的演示"。

## 4. 已知会翻车的地方（照此规避）

| 现象 | 原因 | 规避 |
|---|---|---|
| 顶栏写着 `live` 但实际没出网 | 模式来自服务端响应头 `x-intentform-llm-mode`，服务没起来时会显示"未知" | 先 `curl -i /api/generate` 看响应头，再开录 |
| 学生页选项点了不亮 | 已在 `f63613d` 修复；若在旧 commit 上录必然复现 | 录制前 `git log --oneline -1` 必须晚于 `f63613d` |
| 发布报 403 | `APP_ORIGIN` 与浏览器地址不一致（含 `changeOrigin` 改写 Host） | 用同一个 `127.0.0.1:<port>` 打开，别混用 `localhost` |
| 生成页点了没反应 | 后端没起或 `/api` 代理指错端口 | 开录前跑一次 `verify.mjs`，它自己起服务验证同一套路径 |
| 视频里出现"待补"字样 | 计划模板里允许留空，但视频不能展示未完成态 | 录前把要展示的页面都点一遍 |
